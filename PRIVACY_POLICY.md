# Privacy Policy for EZ Translate Lite

Last updated: March 13, 2026

EZ Translate Lite ("the Extension") is developed and maintained by Abel Liu.

Contact: sylar19951010@gmail.com

## Summary

- The Extension does not operate a developer backend to collect user data.
- The Extension does not include analytics or advertising trackers.
- Translation requests are sent directly from the user's browser to the user-selected third-party AI provider.
- User settings are stored in browser storage (`chrome.storage.local` by default, and `chrome.storage.sync` only if the user enables sync).

## Data Processed by the Extension

The Extension may process the following data solely to provide translation features:

- Text explicitly selected or entered by the user for translation.
- User configuration data, such as:
  - selected provider
  - API key
  - model settings
  - language preferences
  - feature toggles

## How Data Is Used

Data is used only to provide the Extension's translation functionality, including:

- creating translation requests
- returning translation results in the page or popup
- saving user preferences so the Extension works as configured

## Data Storage

- By default, settings are stored in `chrome.storage.local` on the user's device.
- If the user enables browser account sync, settings are stored in `chrome.storage.sync` and synchronized across the user's signed-in browser profile.
- The developer does not receive this storage data on developer-operated servers.

## Third-Party Services

The Extension allows users to configure third-party AI/LLM providers. When translation is triggered, user-selected text and required request parameters are sent directly to the selected provider endpoint.

These providers process data under their own terms and privacy policies. Users are responsible for reviewing and accepting the selected provider's policies.

## Data Sharing

- The Extension does not sell user data.
- The Extension does not share data with unrelated third parties.
- Data is transmitted only to the user-configured translation provider to fulfill user requests.

## Security

The Extension uses browser-provided storage and network APIs. No method of transmission or storage is 100% secure, but the Extension is designed to minimize data use and only process data necessary for translation.

## User Control and Deletion

Users can control or delete data at any time by:

- removing or editing settings in the Extension options page
- disabling browser sync (if enabled)
- clearing extension storage via browser settings
- uninstalling the Extension

## Changes to This Policy

This policy may be updated when features or compliance requirements change. The latest version will be published at this URL.

## 简要说明

- 本扩展不提供开发者自建后端来收集用户数据。
- 本扩展不包含统计分析或广告追踪器。
- 翻译请求由用户浏览器直接发送到用户自行选择的第三方 AI 服务商。
- 用户设置默认存储在 `chrome.storage.local`，仅在用户主动开启同步时使用 `chrome.storage.sync`。

## 本扩展处理的数据

本扩展仅为实现翻译功能，可能处理以下数据：

- 用户主动选中或输入并请求翻译的文本。
- 用户配置数据，例如：
  - 选择的服务商
  - API Key
  - 模型设置
  - 目标语言偏好
  - 功能开关状态

## 数据用途

上述数据仅用于实现翻译相关功能，包括：

- 生成翻译请求
- 在页面或弹窗中展示翻译结果
- 保存用户偏好设置以维持扩展配置

## 数据存储

- 默认情况下，设置存储在用户设备的 `chrome.storage.local`。
- 若用户主动开启浏览器账号同步，设置将存储在 `chrome.storage.sync` 并在同一账号的浏览器间同步。
- 开发者不会在自有服务器上接收这些浏览器存储数据。

## 第三方服务

本扩展允许用户配置第三方 AI/LLM 服务商。触发翻译时，用户选中文本及必要请求参数会直接发送到用户选择的服务商接口。

第三方服务商将依据其自身服务条款与隐私政策处理数据。用户应自行阅读并确认所选服务商的相关政策。

## 数据共享

- 本扩展不会出售用户数据。
- 本扩展不会向无关第三方共享数据。
- 数据仅会在用户发起翻译时发送给用户配置的翻译服务商。

## 安全性

本扩展使用浏览器提供的存储与网络 API。任何传输或存储方式都无法保证绝对安全，但本扩展遵循最小化原则，仅处理翻译所必需的数据。

## 用户控制与删除

用户可随时通过以下方式控制或删除数据：

- 在扩展设置页修改或删除配置
- 关闭浏览器同步（如已开启）
- 在浏览器中清理扩展存储
- 卸载扩展
